## 17.1 — Is there a native Salesforce integration?

The Enterprise Salesforce connector synchronizes selected account identifiers and case status in one direction from MeridianDesk. It does not copy attachment bodies or implement arbitrary bidirectional object synchronization. The customer supplies an appropriately scoped Salesforce integration account.

## 17.2 — Can notifications be sent to Microsoft Teams or Slack?

Customers can configure outgoing webhook notifications to a Teams or Slack workflow they manage. There is no vendor-hosted bot with access to all channel history. Customers control destination permissions and should avoid including sensitive case content in notification templates.

## 17.3 — What is the maximum attachment size?

An individual attachment can be at most 100 MB. Executable files and password-protected archives are blocked, and accepted uploads pass through malware scanning before download is enabled. Increasing the tenant storage quota does not increase the per-file size limit.

## 17.4 — Does the product support inbound email case creation?

Each tenant can enable a generated inbound email address that creates new cases and appends replies to existing cases. Message size including attachments is limited to 25 MB. Customers can restrict accepted sender domains, but email ingestion is not an identity-verification mechanism.

## 17.5 — Can tenants run custom server-side code inside the product?

No. Tenants can configure routing rules and published webhook actions, but cannot upload executable plugins, database procedures or arbitrary server-side scripts. Custom processing must run in customer-managed middleware using the public API.
